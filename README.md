# Yasprosil AI Portfolio

Современный адаптивный одностраничный сайт-портфолио на Next.js и Tailwind CSS.

Это статичный промо-сайт для AI/maker-разработчика: без backend, базы данных, CMS,
авторизации, админки и лишнего функционала.

## Запуск

```bash
npm install
npm run dev
```

Локальный адрес по умолчанию: `http://127.0.0.1:3000`.

## Структура

- Header
- Hero
- Services
- Projects
- Process
- Skills
- About
- Contact
- Footer

## Что внутри

- компонентная структура;
- данные проектов, услуг и навыков вынесены в массивы;
- якорная навигация;
- темный технологичный стиль;
- адаптивная мобильная версия;
- простые hover-эффекты;
- контактные CTA на Telegram и email;
- оптимизированное фото для блока “Обо мне”.
